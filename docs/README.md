# Docs — my working notebook

This folder is the "back office" for the project: my personal notes, not the
recruiter-facing stuff. The main [README](../README.md) is the front door; this is
where the detailed thinking lives.

## What's in here

| File | What it's for |
|------|---------------|
| [vision.md](vision.md) | The north-star: what the finished system looks like, the target metrics, and the resume bullets. Read this when the work feels like a tutorial. |
| [progress-log.md](progress-log.md) | A dated journal of what we did each day. Read this first when coming back to the project. |
| [concepts.md](concepts.md) | Plain-language explanations of things as I learn them (connections, pools, etc.). |
| [design-decisions.md](design-decisions.md) | Why we chose X over Y. Useful for interviews ("walk me through why you did this"). |

*As the project grows, add new files here and list them in the table above so nothing
gets lost.*
